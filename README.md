# 个人工具箱

离线单页小工具集合，纯 HTML/CSS/JS、无需构建，可部署到 GitHub Pages，能装成手机 / 电脑上的应用。

## 本地打开

推荐用本地服务器打开（离线缓存、安装成应用、工具之间互传图片都需要 http(s)）：

```bash
cd personal-tools
python -m http.server 8080
```

访问 `http://127.0.0.1:8080/`。直接双击 `index.html` 也能用基本功能。

## GitHub Pages

1. 把本仓库推到 GitHub（Public）
2. Settings → Pages → Branch 选 `main`，目录 `/ (root)`
3. 访问：`https://你的用户名.github.io/仓库名/`

## 装成应用、断网可用

- 电脑（Chrome / Edge）：点工具箱顶栏的「安装」，或地址栏右侧的安装图标
- iPhone（Safari）：分享 → 添加到主屏幕；安卓（Chrome）：菜单 → 安装应用
- 打开过一次之后，周报和拼图断网也能打开、照常使用；共享剪贴板断网时能看本机历史，联网后自动重连
- 发布新版本后，打开时顶部会提示「工具箱有新版本，刷新后生效」，点「立即刷新」即可

## 三个工具

### 周报填写

- 边填边按项目分组、同项目按进度从低到高排好，预览就是复制出去的样子
- 粘贴多行文字自动按行拆成多条：识别开头的「1、」「- 」等序号、「【项目】」和末尾的「（80%）」，拆完可撤销；粘贴整份周报会直接打开「导入成稿」
- 往期存档：复制报告、下周转本周、清空、导入之前都会自动存一份，跨周打开时也会存下上周的草稿；每周只留最新一份，最多 104 周，可复制、查看、恢复到编辑区、删除（可撤销）
- 备份：「往期 → 导出备份」把草稿和全部往期存成一个 `.json`；换电脑后「导入备份」，往期按周合并
- 只搬当前这份：一端「复制报告」，另一端「导入成稿」粘贴

### 图片拼接

- 竖拼、横拼、宫格（每行 2 / 3 / 4 张）
- 长截图自动去重：竖拼时找出相邻截图重叠的部分自动裁掉，顶部状态栏、底部导航栏这类固定栏也能识别；缩略图上标出每张裁了多少，可以关掉
- 导出 PNG（无损）或 JPG（更小），导出宽度可选原尺寸 / 1440 / 1080 / 720
- 标注、打码、裁剪

### 共享剪贴板

- 输入同一个房间口令的设备之间互传文字、截图和文件（单个文件不超过 8 MB）
- 端到端加密：口令经 PBKDF2 + HKDF 派生出 AES-GCM 密钥和频道名，公共 MQTT 服务器只看得到密文；从旧版升级时，所有设备都要刷新一次才能互通
- 扫码进房：二维码是带口令的进房链接（口令在 `#` 后面，不会发给服务器，打开后立刻从地址栏抹掉），别发给不该进房的人
- 本机保留最近 40 条历史，刷新不丢；单条删除只删本机
- 页面在后台时收到新内容会弹系统通知（需要授权）

## 工具之间互通

打开根目录即可在一个浏览器标签里切换工具，已打开过的工具不会卸载。共享剪贴板进过房间的话，打开工具箱时会在后台自动连上；切去拼图 / 写周报也保持连接，收到内容时顶栏显示未读数并弹出提醒。也可直接访问 `#weekly` / `#stitch` / `#clipboard`。

- 拼图 → 剪贴板：拼好或标注好的图点「发到剪贴板」，直接发进当前房间（还没进房会提示先进房）
- 剪贴板 → 拼图：收到图片后点「拼接最近 N 张图」，自动切到拼图并加进去

## 目录

```text
index.html                 # 顶栏 Tab 壳：同页切换三个工具（iframe 保活），安装按钮、跨工具转发、系统通知
manifest.webmanifest       # 应用名称、图标、主题色
sw.js                      # 离线缓存：先给缓存秒开，后台拉新，有新版本时通知页面
assets/pwa.js              # 工具页单独打开时注册离线缓存、显示新版本提示
icons/                     # 应用图标
tools/weekly-report/       # 周报填写助手
tools/image-stitch/        # 图片拼接 + 标注
tools/clipboard/           # 共享剪贴板（MQTT 公共通道同步，vendor/ 下是 mqtt 和二维码库）
```

新增工具：在 `tools/` 下新建目录放 `index.html`，再在根目录 `index.html` 的 `TOOLS` 数组里加一项（id、名称、路径、一句话说明），并在 `ICONS` 里给同一个 id 配一个图标；要断网可用，把页面路径加进 `sw.js` 的 `PRECACHE_URLS`。
