周报填写助手

草稿自动保存在本机、每周自动存档，断网也能用 · 边填边按项目、进度自动整理

! 请先填写工作事项
项目

本周工作重点

0 项

进度填 1–100，− / + 每次 5%，做完点「完成」；回车新增下一条，粘贴多行文字会按行拆成多条。同项目内按进度从低到高自动排好。

下周工作计划

0 项

底部「未完成写入下周」可一键带入本周没做完的事项；按住序号拖动可调整同项目内的先后；同样支持粘贴多行拆条。

预览

按项目分组、同项目按进度从低到高，复制出去就是这样

换设备继续写：一端「复制报告」发到微信 / 备忘录，另一端「导入成稿」粘贴即可；连往期一起搬家用「往期 → 导出备份」

导入成稿

粘贴另一端「复制报告」得到的全文，会替换当前的本周和下周内容。Ctrl + Enter 可直接确认。

往期周报

复制报告、下周转本周、清空、导入之前都会自动存一份，跨周打开时也会存下上周的草稿；同一周只留最新一份，最多保留 104 周

备份包含当前草稿和全部往期，换电脑、清浏览器数据前导出一份
